Level 2: containers

A C4 container is a runnable unit, not necessarily a Docker container. Three here, plus the data store.

Console (browser)

One self-contained HTML file. Draws the floor, runs the detector and the zone correlator, holds the runbook catalogue, drafts triage requests, and tracks confirmation state.

Owns: detection logic, the approve button.

Backend (FastAPI)

Polls an adapter every 2 s and broadcasts snapshots; validates tokens; persists incidents and timeline events; syncs tickets; serves the triage endpoint.

Owns: authority: every write and every model call.

Database (PostgreSQL)

Incidents, timeline events, runbook runs, month-to-date AI spend. Telemetry history lives in Prometheus, not here.

Owns: the incident record (together with the ticket).

Phoenix (local)

Receives one OpenTelemetry trace per triage call. Off by default; /healthz reports tracing: off so the gap is visible.

Owns: evaluation evidence.

One complete request: free-text triage to saved incident

Proposing and saving use different request paths. A suggestion is not permission to change state.

Steps 1–4 never write. Step 6 is the only write and carries the exact fields the operator reviewed. The model is not called at step 6.

One complete request: telemetry to approved runbook

1 AdapterPrometheus or simulator returns 24 racks
2 BroadcastWebSocket pushes the snapshot to every console
3 Detectz-score per metric; ceilings 27 °C, 92 %

Security view (STRIDE summary)

ThreatControl
Spoofing an operatorOIDC with PKCE; RS256 JWT validated against the IdP JWKS; no local accounts; dev auth refused in production
Tampering with telemetry or the write pathManagement-network isolation; snapshot schema validation; no import path from the AI module to the incident router (tested)
Prompt injectionOperator text placed as data; rules in the system prompt; post-validation; golden case T8
RepudiationAppend-only timeline with actor; ticket work notes; traces with request id
Information disclosureKey and bearer redacted in spans; identity hashed; TLS everywhere; secrets in a secret manager
Denial of servicePer-user rate limit, monthly budget, input caps, WAF
Elevation of privilegeShift-lead role required to approve; no actuation endpoint exists; firewall denies BMS/PDU
