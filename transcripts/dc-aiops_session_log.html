Weekend 1 · 5–6 September 2026 — Foundations of agentic AI

What the weekend teaches: the agent loop (perceive → reason → act → observe → verify), the harness as contractor, autonomy versus blast radius, stop conditions set by the harness.

Principles that survived into CLAUDE.md: human approves, agent executes; never actuate equipment; bound every model call; stop caps belong to the harness.

Weekend 2 · 12–13 September 2026 — Agentic coding harnesses and specification-driven development

What the weekend teaches: spec → plan → implement → verify → iterate; the four control surfaces (prompt, context, loop, graph); a criterion is a sentence with a command attached; test the test; CLAUDE.md, permissions and a verify script as the loop.
